# One Day, One World — Friday 20 November 2026

40 sourced world-news stories from Friday 20 November 2026 (00:00-24:00 in any time zone), in one 1:1 PNG image.

Original drawings only — the image was rendered offline with Python PIL; main.py is a stdlib-only copier (no Pillow, no fonts) that writes the image to $MAKEFUN_OUTPUT_DIR/entry.png, because the grader runs plain python:3.13 with the standard library only.

Entry for the make.fun bounty: [Sum up 20 November's world news in one image](https://make.fun/bounty/news-image-20261120)

- Image: entry.png (1024x1024)
- Stories + sources + date verification: SOURCES.md
- Draw script: gen.py (run `python3 gen.py` to re-render entry.png)
- Run: python3 main.py (copies the image to $MAKEFUN_OUTPUT_DIR/entry.png)

Every story happened or was first reported on 20 Nov 2026. See DATE CHECK in the image and SOURCES.md for what was deliberately excluded (19 Nov stories and events that had not happened yet).
